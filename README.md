# التلال | موقع محمصة قهوة

موقع لبراند قهوة منزلي، مبني بـ Next.js و React و TypeScript و CSS Modules.

## التشغيل

```bash
git clone https://github.com/huda0musallam/tilal-web.git
cd tilal-web
npm install
npm run dev
```

وافتح `http://localhost:3000`

البيانات جاية من API أونلاين مبني بـ json-server على Render:

- الكود: [tilal-api](https://github.com/huda0musallam/tilal-api)
- الرابط: https://tilal-api.onrender.com/

أول تحميل ممكن ياخد حوالي دقيقة، لأنه السيرفر المجاني بينام إذا ما حدا استخدمه.
